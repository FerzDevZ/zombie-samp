# MEMORY — Invariant & Post-Mortem

Format tiap baris:
`- **[YY-MM-DD · Komponen]**: <gejala> → **Root Cause**: <penyebab> → **Invariant Rule**: <aturan permanen>.`

## Invariant Arsitektur (ditetapkan sebelum kode ditulis)

- **[25-11-18 · Tick]** Server akan mati jika AI zombie berjalan tiap frame → **Root Cause**: `OnPlayerUpdate` + loop MAX_PLAYERS adalah pola default PAWN lama → **Invariant Rule**: tidak ada logika gameplay di `OnPlayerUpdate`; semua kerja lewat `y_timers` dengan budget per tick dan slice per zona.

- **[25-11-18 · AI]** Zombie berdiri diam di depan pemain adalah bug yang paling sering dilaporkan → **Root Cause**: A* gagal di node graph yang buruk dan tidak ada rencana cadangan → **Invariant Rule**: setiap kegagalan pathfinding 2× berturut wajib fallback ke mode CHASE langsung-ke-target; zombie tidak boleh idle jika target terlihat.

- **[25-11-18 · Combat]** Zombie memukul menembus dinding merusak kepercayaan pemain total → **Root Cause**: damage diterapkan hanya berdasarkan jarak → **Invariant Rule**: setiap damage (PvE & PvP) melewati `ApplyVerifiedDamage` dengan LOS ColAndreas; tidak ada jalur damage kedua.

- **[25-11-18 · Item]** Dupe item adalah satu-satunya bug yang bisa membunuh ekonomi permanen → **Root Cause**: dua query terpisah (kurangi sumber, tambah tujuan) tanpa lock → **Invariant Rule**: semua perpindahan item memakai `Inventory_MoveTx` (`SELECT ... FOR UPDATE` → update → commit) dan menulis `item_ledger`.

- **[25-11-18 · Loot]** Loot ESP muncul otomatis jika pickup bersifat global → **Root Cause**: `CreateDynamicPickup` tanpa parameter playerid → **Invariant Rule**: pickup loot selalu player-specific; objek loot tidak pernah global.

- **[25-11-18 · UI]** HUD berhenti update atau tombol tidak bisa diklik setelah beberapa menit → **Root Cause**: kebocoran `PlayerTextDraw` menembus 256 slot → **Invariant Rule**: satu modal aktif pada satu waktu (`CloseActiveUI`), frame statis memakai Global TextDraw, headroom minimal 60 slot, semua destroy lewat `SafeDestroyPlayerTD`.

- **[25-11-18 · Mobile]** Pemain Android tidak bisa memakai fitur apa pun yang hanya keybind → **Root Cause**: interaksi dirancang PC-first lalu ditambal → **Invariant Rule**: setiap interaksi `[Y]` wajib punya command fallback yang setara sejak fase implementasinya, bukan di akhir.

- **[25-11-18 · Scope]** Proyek gagal karena custom map, CEF, dan sistem faction RP masuk sebelum loop inti stabil → **Root Cause**: tidak ada daftar "tidak dikerjakan" → **Invariant Rule**: fitur di luar 9 fase ROADMAP tidak dikerjakan sampai fase 8 lulus gate load test.

- **[25-11-18 · SQL]** `001_init.sql` gagal di MariaDB 10.11 (`ERROR 1064` dekat kolom `condition`) → **Root Cause**: `condition` adalah reserved word MariaDB/MySQL → **Invariant Rule**: kolom dengan nama berpotensi reserved selalu diberi prefix domain (`weapon_condition`), dan setiap migrasi divalidasi dengan menjalankannya di MariaDB container, bukan dibaca manual.

- **[25-11-18 · FCNPC]** `error 025 function heading differs from prototype` pada ketiga callback FCNPC di `main.pwn` → **Root Cause**: compiler PAWN mencocokkan `public` dengan `forward` plugin *termasuk nama parameter*; parameter kita `zombieid` sedangkan header menulis `npcid` → **Invariant Rule**: nama parameter callback plugin wajib identik dengan header (`npcid`, `issuerid`, `amount`, `weaponid`, `bodypart`, `killerid`, `reason`); body langsung mendelegasikan ke `Zombie_Hook*` agar modul tetap boleh memakai nama domain.

- **[25-11-18 · FCNPC]** `error 025` juga muncul bila callback FCNPC dideklarasikan di dalam file include (`.inc`), meski isinya sama → **Root Cause**: makro rename ALS dari `fcnpc.inc` hanya berlaku pada file utama → **Invariant Rule**: semua `public FCNPC_On*` tinggal di `main.pwn`; file include hanya berisi `stock Zombie_Hook*`.

- **[25-11-18 · AI]** Zombie mendengar suara tapi berhenti di tempat dan kembali IDLE → **Root Cause**: cabang LOD di `ZombieAI_Process` memanggil `FCNPC_Stop` untuk setiap zombie tanpa pemain terdekat, menghapus state INVESTIGATE → **Invariant Rule**: `FCNPC_Stop` hanya dipanggil bila `zaiHasNoisePoint == false`; investigasi memakai `ZombieAI_Investigate` bersama dengan memori suara `ZOMBIE_NOISE_MEMORY_MS`.

- **[25-11-18 · ColAndreas]** Semua spawn zombie gagal setelah boot bersih → **Root Cause**: `ColAndreas.cadb` belum ada, `CA_RayCastLine` selalu 0, `Director_FindGround` return false → **Invariant Rule**: raycast ground selalu punya fallback `zoneZ` dan status `CA_Init()` dicatat di log boot; `.cadb` adalah artefak deploy, bukan bagian repo.

- **[25-11-18 · Combat]** Zombie berdiri 4 m di depan pemain dan tidak pernah memukul → **Root Cause**: `FCNPC_GoToPlayer` dipanggil dengan `radius` 4.0 sedangkan `ZOMBIE_ATTACK_RANGE` 2.6, jadi NPC berhenti di luar jangkauan melee → **Invariant Rule**: `ZOMBIE_APPROACH_DIST` wajib lebih kecil dari `ZOMBIE_ATTACK_RANGE`, dan sebelum `FCNPC_MeleeAttack` selalu dipanggil `FCNPC_Stop` (NPC yang masih berjalan memukul udara).

- **[25-11-18 · Zona]** "Noise jalan tapi zombie tidak menyerang" juga terjadi sah di zona HUB → **Root Cause**: `ZombieAI_AcquireTarget` menolak target di zona hub, sementara `/test` tetap men-spawn zombie di sana tanpa menjelaskan → **Invariant Rule**: setiap alat uji yang berhubungan dengan agresi wajib melaporkan status zona dan menolak dijalankan di hub dengan pesan yang jelas.

- **[25-11-18 · Spawn]** Pemain muncul di tengah laut (0,0,0) → **Root Cause**: `main.pwn` tidak punya `AddPlayerClass`, SA-MP memakai posisi default → **Invariant Rule**: minimal satu `AddPlayerClass` di koordinat `SPAWN_*` wajib ada, dan `OnPlayerSpawn` memindahkan pemain yang masih di 0,0 ke kamp.

- **[25-11-18 · Proteksi]** Pemain baru tidak bisa menarik zombie dengan tembakan selama 10 menit → **Root Cause**: `PLAYER_GRACE_MS` dipakai juga di `Noise_EmitFromPlayer` → **Invariant Rule**: grace hanya untuk damage PvP; noise selalu dipancarkan, dan durasinya 15 detik, bukan 10 menit.

- **[25-11-18 · Zombie Feel]** Zombie terlihat seperti orang tawuran karena semua tipe memukul dengan animasi tinju yang sama dan serempak → **Root Cause**: `ztMeleeStyle` diisi nilai tidak valid (8) dan `ztAttackDelayMs` terlalu pendek tanpa jitter → **Invariant Rule**: `ztMeleeStyle` hanya boleh `FIGHT_STYLE_*` yang sah dan diterapkan lewat `FCNPC_SetFightingStyle` saat NPC dibuat; delay serangan selalu diberi jitter `random(delay/2)`.

- **[25-11-18 · Zombie Feel]** Zombie lambat terlihat meluncur (kaki jalan, badan geser) → **Root Cause**: `FCNPC_GoToPlayer` memakai `FCNPC_MOVE_TYPE_RUN` untuk semua tipe padahal speed Walker 0.155 (skala walk) → **Invariant Rule**: `moveType` dipilih dari kecepatan (`<= 0.35` → WALK, selain itu RUN), dan satuan speed selalu skala FCNPC (`FCNPC_MOVE_SPEED_*`), bukan m/s.

- **[25-11-18 · Kendaraan]** Server bisa dibanjiri mobil oleh satu pemain → **Root Cause**: tidak ada batas kepemilikan kendaraan uji → **Invariant Rule**: kendaraan uji memakai slot ring `MAX_TEST_VEHICLES` dan yang terlama dihancurkan otomatis; tidak ada sistem kepemilikan sampai fase garasi.

- **[25-11-18 · Zumbi]** Gerombolan zombie saling memukul dan saling membunuh → **Root Cause**: `FCNPC_MeleeAttack` punya cone area, `FCNPC_OnTakeDamage` meneruskan damage NPC→NPC ke `Damage_Apply` → **Invariant Rule**: damage dari `IsPlayerNPC(issuerid)` selalu ditolak; tidak ada friendly fire antar NPC, apa pun yang dikirim engine.

- **[25-11-18 · Zumbi]** Zombie menumpuk di satu titik di depan pemain sehingga terlihat seperti tawuran → **Root Cause**: semua NPC mengejar posisi pemain yang sama (`FCNPC_GoToPlayer`) → **Invariant Rule**: fase chase memakai `ZombieAI_MoveToRing` — setiap `zombieid` mendapat bearing tetap `(zombieid * 47) % 360` di lingkaran `ZOMBIE_APPROACH_DIST + 0.6`, jadi mereka mengepung dari banyak arah.

- **[25-11-18 · MySQL]** Plugin `mysql.so` gagal dimuat: `Failed (log-core.so: cannot open shared object file)` → **Root Cause**: build Debian-static menautkan `log-core.so` sebagai dependensi dinamis, tidak disertakan di `plugins/` dan tidak ada di loader path → **Invariant Rule**: `log-core.so` wajib ada di `plugins/` (dan root), server dijalankan lewat `scripts/run-server.sh` yang mengeset `LD_LIBRARY_PATH`; jangan pernah `sampctl run` polos untuk build ber-MySQL.

- **[25-11-18 · MySQL]** `error 017 undefined symbol mysql_unref_options` + `warning 202` pada `mysql_set_option` → **Root Cause**: include R41-4 memakai `mysql_connect_file(file)` tanpa parameter opsi; `mysql_unref_options` baru ada di seri R41-5 → **Invariant Rule**: untuk R41-4 selalu `mysql_connect_file("mysql.ini")` dan jangan memakai API `*_options` kecuali sudah diverifikasi ada di `include/a_mysql.inc`.

- **[25-11-18 · MySQL]** `warning 202 number of arguments does not match definition` pada `cache_get_value_name_int` → **Root Cause**: di R41-4 fungsi ini **wajib punya parameter tujuan** (`cache_get_value_name_int(row, "col", var)`), bukan mengembalikan nilai → **Invariant Rule**: tidak pernah memakai `cache_get_value_*` sebagai ekspresi; selalu deklarasikan variabel tujuan lalu baca variabelnya.

- **[25-11-18 · PAWN]** `warning 213 tag mismatch: expected Float, found none` pada variabel posisi → **Root Cause**: `new Float:x, y, z;` hanya memberi tag pada variabel pertama → **Invariant Rule**: setiap variabel Float dideklarasikan terpisah (`new Float:x; new Float:y;`).

- **[25-11-18 · Auth]** Password tidak boleh di-hash di main thread dan tidak boleh dibandingkan manual → **Root Cause**: bcrypt sengaja lambat (cost 12), memblokir tick jika sinkron → **Invariant Rule**: selalu `bcrypt_hash`/`bcrypt_verify` versi callback (`Account_OnPasswordHashed`, `Account_OnPasswordVerified`), dan `#include "../include/samp_bcrypt.inc"` sebelum modul akun.

- **[25-11-18 · PAWN]** Include baru `modules/inventory/inventory_persist.inc` isinya diabaikan total tanpa error apa pun (semua `stock` di dalamnya "undefined") → **Root Cause**: path include terlalu panjang untuk buffer pawncc; isi file tidak diproses sama sekali dan `#error` di dalamnya pun tidak muncul → **Invariant Rule**: path include relatif maksimal ~35 karakter; kalau sebuah modul tiba-tiba "undefined" padahal `#include`-nya ada, **rename file lebih pendek dulu** sebelum menduga bug logika (`invpers.inc`).

- **[25-11-18 · PAWN]** `warning 219 local variable "itemName" shadows a variable at a preceding level` + `error 035 argument type mismatch` pada `sizeof(itemName)` → **Root Cause**: field enum `itemName[24]` di `items.inc` adalah simbol global, jadi variabel lokal bernama sama menabraknya → **Invariant Rule**: variabel lokal item selalu bernama `itemLabel`, tidak pernah menyalin nama field enum.

- **[25-11-18 · Persistensi]** Slot inventory yang dikosongkan harus hilang dari DB tanpa risiko baris hantu → **Root Cause**: `DELETE` + `INSERT` adalah dua query async di pool berbeda (tidak atomik) → **Invariant Rule**: `inventory` disimpan sebagai SATU `REPLACE` dengan seluruh 20 slot (slot kosong = `item_id 0`, loader melewatinya); tabel `weapons` memakai unique `(char_id, weapon_id)` + `ON DUPLICATE KEY UPDATE`.

- **[25-11-18 · Stash]** `/interact` di Stash Camp hanya menyembuhkan, isi stash tidak bisa diakses → **Root Cause**: tabel `stash` sudah ada tapi tidak ada modul yang memuat/menyimpannya → **Invariant Rule**: stash mengikuti pola inventory — satu `REPLACE` berisi seluruh `MAX_STASH_SLOTS` (slot kosong `item_id 0`), dan setiap perpindahan item menulis `item_ledger` (`stash_in`/`stash_out`) lalu menyimpan kedua sisi.

- **[25-11-18 · Durabilitas]** Senjata tidak pernah aus walau `weapon_condition` ada di DB → **Root Cause**: tidak ada jalur damage kondisi; senjata baru dari spawn juga tidak punya baris DB → **Invariant Rule**: kondisi senjata diinisialisasi malas (`<= 0` → `WEAPON_CONDITION_MAX`) di `Inventory_DamageWeapon`, turun `WEAPON_CONDITION_PER_SHOT` per tembakan di `OnPlayerWeaponShot`, dan `SetPlayerAmmo(...,0)` + `Weapons_Save` saat mencapai 0.

- **[25-11-18 · Barricade]** Barricade Kit tidak bisa dipakai dan durabilitas item tidak pernah turun → **Root Cause**: tidak ada consumer untuk kategori TOOL → **Invariant Rule**: item kategori `ITEM_TOOL` dipakai lewat `InventoryUI_Use` → aksi nyata dulu, baru `Inventory_DamageItem(..., ITEM_DURABILITY_USE_COST)`; jangan pernah mengurangi durabilitas tanpa efek permainan.

- **[25-11-18 · Loot]** Pemain tidak bisa mengambil loot zombie walau item terlihat, dan label 3D menyuruh "tekan Y" padahal tidak ada handler Y untuk loot → **Root Cause**: pickup dibuat dengan `type 1` (tidak terpicu saat pemain berjalan melewatinya) dan satu-satunya jalur ambil adalah `OnPlayerPickUpDynamicPickup` → **Invariant Rule**: pickup loot memakai `type 2`, dan selalu ada jalur kedua `Loot_TakeNearest` yang dipanggil dari tombol `KEY_YES` (prioritas sebelum hotspot) serta perintah `/take` untuk mobile.

- **[25-11-18 · ColAndreas]** `CA_Init()` gagal walau `ColAndreas.cadb` sudah ada di server → **Root Cause**: plugin mencari path huruf kecil `scriptfiles/colandreas/ColAndreas.cadb`, sedangkan file ditaruh di `scriptfiles/ColAndreas/` → **Invariant Rule**: `.cadb` selalu di `scriptfiles/colandreas/` (lowercase, symlink `ColAndreas` sebagai jaring pengaman), plugin dan `.cadb` wajib dari release yang sama, dan setiap boot harus mencetak hasil `CA_RayCastLine` uji agar kegagalan data tidak lolos diam-diam.

- **[25-11-18 · Barricade]** Barricade hanya objek visual karena tidak ada collision untuk zombie → **Root Cause**: `CreateDynamicObject` tidak pernah masuk collision world ColAndreas → **Invariant Rule**: setiap barricade membuat dua objek — `CreateDynamicObject` untuk mata pemain dan `CA_CreateObject(..., add = true)` untuk collision zombie — dan keduanya dihancurkan bersama (`CA_DestroyObject`).

- **[25-11-18 · Crafting]** Butuh sistem craft tanpa merusak ledger item → **Root Cause**: crafting melibatkan 3 operasi (ambil bahan A, ambil bahan B, beri hasil) dan MySQL tidak punya transaksi lintas query di sini → **Invariant Rule**: urutan craft selalu `Consume A` → `Consume B` → `Grant hasil`; setiap kegagalan mengembalikan bahan yang sudah diambil lewat `Inventory_Grant(..., "craft_refund")` sehingga tidak ada item yang menguap.

- **[25-11-18 · Timer]** Barricade tidak pernah dimuat saat boot walau kodenya ada → **Root Cause**: fungsi dimuat sebagai `stock`, sedangkan `SetTimer` hanya bisa memanggil fungsi `public`; timer gagal tanpa pesan → **Invariant Rule**: setiap fungsi yang dipanggil lewat `SetTimer`/`SetTimerEx` wajib `public` + `forward`.

- **[25-11-18 · Enum]** Perbandingan `Zombie_GetType(id) != E_ZOMBIE_TYPE:ZT_SCREAMER` tetap memicu warning 213 → **Root Cause**: nilai enum di sisi kanan tidak membawa tag saat dibandingkan dengan hasil fungsi bertag → **Invariant Rule**: bandingkan tipe enum dengan cast `_:` di kedua sisi.

- **[25-11-18 · Skema]** Menghapus akun meninggalkan karakter, base, barricade, dan inventory yatim → **Root Cause**: `characters.account_id` tidak punya foreign key, jadi CASCADE tidak pernah berjalan → **Invariant Rule**: setiap tabel anak wajib FK `ON DELETE CASCADE` ke induknya; migrasi `003_character_account_fk.sql` menambal ini dan harus ada di setiap deploy baru.

- **[25-11-18 · Performa]** `Base_Tick` memanggil `FCNPC_GetPosition` 40 x N zombie tiap 2 detik → **Root Cause**: posisi zombie diambil di dalam loop barricade → **Invariant Rule**: posisi NPC diambil SEKALI per tick ke array, lalu dipakai semua konsumen; `FCNPC_GetPosition` tidak pernah dipanggil di loop bersarang.

- **[25-11-18 · Anti-cheat]** Deteksi kecurangan tanpa bukti berisiko menghukum pemain lag → **Root Cause**: satu anomali tidak membedakan lag dan cheat → **Invariant Rule**: flag selalu ditulis ke `anticheat_flags` lebih dulu, eskalasi bertingkat (freeze 2,5 detik di 3 flag, kick di 6 flag dalam 2 menit), dan tidak pernah kick pada flag pertama.

- **[25-11-18 · Skills]** XP hanya ditambahkan langsung ke `psXp`, level tidak pernah naik → **Root Cause**: `Zombie_AwardKill` menulis XP sendiri tanpa pipeline level-up → **Invariant Rule**: semua penambahan XP wajib lewat `Skills_AddXp`, yang menangani level, poin skill, toast, dan simpan DB sekaligus.

- **[25-11-18 · Shelter]** Menyimpan posisi saat pemain logout di dalam shelter membuat pemain login di koordinat interior pada world 0 → **Root Cause**: `Account_SaveCharacter` menulis `GetPlayerPos` apa adanya, sedangkan interior/virtual world tidak dipulihkan → **Invariant Rule**: posisi yang dipersistensi harus selalu koordinat dunia nyata; jika `psInShelter` aktif, simpan koordinat hub.

- **[25-11-18 · AI Target]** Zombie bisa menarget pemain di dalam shelter karena pencarian target memakai jarak koordinat saja → **Root Cause**: `Hash_NearestPlayer` tidak memfilter zona aman → **Invariant Rule**: target zombie wajib melewati `Player_IsAlive` + `Player_IsSafe`; fungsi bertag yang dipakai lintas include dideklarasikan `forward` agar tidak memicu warning 208.

- **[25-11-18 · Anti-cheat]** Deteksi DPS butuh baseline, bukan tebakan → **Root Cause**: batas damage per detik berbeda per senjata dan per level skill → **Invariant Rule**: ambang DPS dihitung longgar (320/detik, ~3x rifle normal) supaya build legal tidak pernah kena, flag tetap ditulis sebelum damage dibatalkan, dan spike di-reset setelah flag agar tidak memicu beruntun.

- **[25-11-18 · Event]** Event harus memakai sistem yang sudah ada, bukan jalur hadiah terpisah → **Root Cause**: event yang memberi item sendiri akan melewati ledger dan membuka dupe → **Invariant Rule**: Supply Drop memakai `Loot_Spawn`, Blood Moon memakai `Director_TriggerHorde`, Jam Tenang hanya mengubah `Event_NoiseMultiplier`.
